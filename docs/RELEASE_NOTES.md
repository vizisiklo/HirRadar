# HírRadar v1.0.0 – kiadási megjegyzések

Kiadás: 2026. október 12.

A v1.0.0 az Alpha 0.7.15 kiadás funkcióinak rögzített, hivatalosan verziózott alapja. Nincs tudatos működési változtatás az Alpha 0.7.15-höz képest.

## A kiadás részei

Belföldi hírfigyelés; több forrás RSS/Atom/HTML-ellenőrzéssel; ötpercenkénti automatikus ciklus; kulcsszavas, helyi és témaszűrők; mentett nézetek; kizárólag szöveges cikkolvasó; plain text másolás vágólapra; rendszertálcás működés; értesítések; CSV/JSON export; naplózás és ciklusonkénti forrásdiagnosztika; CPU/RAM figyelés; portábilis Windows x64 Release-publish.

## Ismert korlátok

A HTML-olvasók webhelystruktúra-változás miatt idővel hibázhatnak, és néhány cikk nem teljes egészében olvasható. A belföldi relevancia és a kapcsolódó hírek besorolása heurisztikus. A különféle forráskapcsolati címkék nem hitelességi döntések. A közvetlen hírforrások frissessége és rendelkezésre állása külső rendszerektől függ.

A csomag statikus, forráskódszintű ellenőrzést kapott. A 24 órás Windows terheléses teszt és a többféle Windows-builden végzett teljes regresszió nem teljesült automatikusan; ezek eredményét nem szabad késznek feltüntetni.

A Windows EXE nincs digitálisan aláírva; Windows SmartScreen figyelmeztetés előfordulhat.
